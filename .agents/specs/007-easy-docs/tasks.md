# Tasks: Easy Docs

Pré-condição de todas as tarefas: unidade
[`001-portal-do-guia`](../001-portal-do-guia/tasks.md) implementada (instância única do plugin de
docs com `remark-math` e `rehype-katex`, i18n pt-BR/`en`/`es`, sidebar `dgsComponents`
`autogenerated`, `_category_.json` da categoria Easy Docs com a chave do rótulo em
`current.json`, `tableOfContents` de h2 a h6, `trailingSlash: false`, `onBrokenLinks: 'throw'`,
introduções provisórias do Easy Docs e card Easy Docs da página inicial). Cada tarefa termina com
`yarn build` verde e com a conferência dos casos de teste de [`test-cases.md`](./test-cases.md)
que ela impacta.
