# Mejores Prácticas de Seguridad

La seguridad debe integrarse en todas las etapas del ciclo de vida del software. Estas prácticas ayudan a garantizar una infraestructura segura:

---

### **1. Privilegio Mínimo**
Aplica el principio de privilegio mínimo (PoLP) para garantizar que solo los usuarios autorizados tengan acceso a los recursos que necesitan.

---

### **2. Rotación de Credenciales**
Automatiza la rotación de contraseñas y claves de acceso para reducir el riesgo de exposición.

---

### **3. Detección Proactiva**
Implementa herramientas de detección de amenazas como:
- **AWS GuardDuty**
- **Azure Security Center**

Estas herramientas monitorean actividades sospechosas y permiten responder rápidamente a incidentes.

---

### **4. Pruebas de Penetración**
Realiza pruebas de penetración periódicamente para identificar vulnerabilidades antes de que puedan ser explotadas por atacantes.
